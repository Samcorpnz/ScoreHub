# Roles & permissions

Every member of an organisation holds one role, from most to least privileged:

| Role | Can do |
| --- | --- |
| **Admin** | Everything — create and run matches, manage billing, invite/remove members, and change any member's role, including other Admins and Managers. |
| **Manager** | Create, score and end matches, invite/manage Operators and Viewers, and manage tokens and display links. A Manager can't touch another Admin's or Manager's membership, and doesn't get billing access. |
| **Operator** | Create, score and end matches from the dashboard and control panel. Can't manage members, tokens or billing. |
| **Viewer** | Read-only — can see the dashboard's match list, but has no control panel access. |

## What each role can do

| Task | Admin | Manager | Operator | Viewer |
| --- | --- | --- | --- | --- |
| Score a match on the control panel | Yes | Yes | Yes | No |
| Use Graphics Control and the Player Roster | Yes | Yes | Yes | No |
| Set up a new match, upload fixtures, end a match | Yes | Yes | Yes | No |
| Generate or revoke Bridge, Stream Deck and data feed tokens | Yes | Yes | No | No |
| Regenerate a match's display link | Yes | Yes | No | No |
| Invite, remove and change the role of members | Yes | Operators and Viewers only | No | No |
| Change the plan, add-ons, or payment details | Yes | No | No | No |

<Callout>
  Every organisation must keep at least one Admin — the last Admin can't be demoted.
</Callout>

## Who can invite and manage members

Only **Admin** and **Manager** roles see the Team panel on the Account page. A Manager can invite,
promote, demote, or remove Operators and Viewers, but can't act on another Admin or Manager — that
prevents a Manager from escalating their own or someone else's privilege. Only an Admin can manage
other Admins or Managers.

## Control tokens vs. roles

The role above governs the ScoreHub web app. Bridge laptops, Stream Deck/webhook integrations and
data feeds authenticate separately, using long-lived tokens issued to your organisation from the
control panel's **Settings** tab. Those tokens aren't tied to an individual member, so removing
someone's membership doesn't revoke a token they generated or copied. After removing someone,
revoke any tokens they had access to and generate new ones, and regenerate the display link for
any match whose links they held.

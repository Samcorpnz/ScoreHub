# Tennis

Tennis matches run as best of 3 or 5 sets on ScoreHub's tennis template.

## Match structure

- Periods: up to 3 × SET (best of 3) or 5 × SET (best of 5)
- Clock: counts up from 0:00, no fixed length
- Scores reset each period: each set starts back at 0–0

## Scoring buttons

- **1** — a point

## Match setup options

When creating the match ([Getting started](/getting-started)), choose the **Match Format**:

- **Best of 3** — most tour, club and doubles matches
- **Best of 5** — Grand Slam men's singles

The control panel shows where you are in the match, for example **SET 2 of 3**, and won't go past
the last set: on the final set the **END SET** button changes to **FINAL SET**. The format is
chosen when the match is created and can't be changed afterwards. ScoreHub doesn't count sets won
— each set's score resets to 0–0 when you end it.

Matches uploaded as fixtures don't have a format, so they aren't limited to a number of sets.

## Running the match

Score the match from the point button above on `/control`. See [Getting started](/getting-started)
for creating the match and finding the control panel link.

# Indoor Cricket

Indoor Cricket matches run as 2 innings of 8 overs each on ScoreHub's indoor cricket template.

## Match structure

- Periods: 2 × INNINGS
- Clock: counts up from 0:00, no fixed length

## Scoring buttons

- **1, 2, 4, 6** — runs scored off a delivery

## Match setup options

When creating the match ([Getting started](/getting-started)), choose the **Wicket Penalty**:

- **-5 runs** — Cricket NZ standard
- **-2 runs** — ICF international

## Running the match

Score the match from the run buttons above on the control panel — see
[Using the control panel](/running-a-match).

Each team also has a **Wicket** button under its score buttons. Selecting it takes the wicket
penalty you chose at setup (5 or 2 runs) off that team's score and adds one to the wicket count
shown on the button. Scores stop at zero — a penalty can't take a team into negative runs — and
displays show each team as runs/wickets (for example `42/3`). A wicket can be undone like any other
action.

## On the display

Viewers on `/display/advanced` see an extra indoor cricket stats panel alongside the base
scoreboard — see [Displaying your score](/displaying-your-score) for the full list of display
routes.

# Rugby League

Rugby League matches run as 2 halves of 40:00 each on ScoreHub's rugby league template.

## Match structure

- Periods: 2 × HALF
- Clock: counts up from 0:00, no fixed length

## Scoring buttons

- **FG (1)** — a field goal (drop goal)
- **CONV/PEN (2)** — a conversion or penalty goal
- **TRY (4)** — an unconverted try
- **CONV TRY (6)** — a try plus successful conversion

## Running the match

Score the match from the buttons above on `/control`. See [Getting started](/getting-started) for
creating the match and finding the control panel link.

# Squash

Squash matches run as best of 5 or best of 3 games to 11 on ScoreHub's squash template.

## Match structure

- Periods: up to 5 × GAME (best of 5) or 3 × GAME (best of 3)
- Clock: counts up from 0:00, no fixed length
- Scores reset each period: each game starts back at 0–0

## Scoring buttons

- **1** — a point

## Match setup options

When creating the match ([Getting started](/getting-started)), choose the **Match Format**:

- **Best of 5** — WSF / PSA major events
- **Best of 3** — circuit / club events

The control panel shows where you are in the match, for example **GAME 2 of 3**, and won't go past
the last game: on the final game the **END GAME** button changes to **FINAL GAME**. The format is
chosen when the match is created and can't be changed afterwards. ScoreHub doesn't count games won
— each game's score resets to 0–0 when you end it.

Matches uploaded as fixtures don't have a format, so they aren't limited to a number of games.

## Running the match

Score the match from the point button above on `/control`.

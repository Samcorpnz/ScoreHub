# The Free plan's one-match limit

On the Free plan, your account can have **one live match at a time**. This page explains what
counts, what you'll see when you reach the limit, and how to carry on.

## What counts as a live match

A match is live from the moment it's started until someone ends it. That means:

- A match you set up with **Set Up a New Match** is live straight away.
- An upcoming fixture becomes live when you select **Start** on it.
- A match stays live after the final whistle until you select **End Match**. Closing the browser
  doesn't end it.

The limit applies across your whole account. If your account has more than one organisation, a
live match in any of them counts.

Upcoming and ended matches don't count — you can have as many of those as you like.

## What you'll see

If a match is already live and you try to set up another, the setup wizard shows:

> Free plan allows one live match at a time across your account — upgrade to Pro for concurrent
> matches

with an **Upgrade plan** link, and the new match isn't created. Starting an upcoming fixture while
another match is live is blocked in the same way — the fixture stays in **Upcoming**.

## Carrying on without upgrading

End the match that's still live:

1. On the dashboard, open the **Live** tab and select **Open Control** on the match.
2. Go to the **Settings** tab and select **End Match**.
3. Set up or start your next match.

Ending a match moves it to **History** and can't be undone, so make sure it really is finished.
Admins and Operators can end a match.

<Callout>
  Make ending the match part of your routine at full time. The most common cause of this message
  is last week's match still being live.
</Callout>

## Running more than one match at once

Pro and Venue allow concurrent live matches across your account — two courts, two fields, or back
to back fixtures that overlap. An Admin can upgrade from **Account → Plan & Billing**; the change
takes effect as soon as payment completes. See
[Upgrading & downgrading](/billing/upgrading-and-downgrading).

## If you downgrade with several matches live

Matches that are already live keep running. The limit applies the next time you set up or start a
match: you won't be able to until every match that's still live has been ended.

# Scoring from a phone

The mobile control panel is a cut-down version of the control panel, laid out for one hand on a
phone. It's for scoring courtside when a laptop isn't practical. It controls the same match as the
full panel, so displays update in exactly the same way.

## Opening it

1. On your phone, sign in to ScoreHub and open the match from the dashboard with **Open Control**.
2. In the control panel's header, select **Mobile**.

The mobile panel opens for that match. To get back, select **Full panel** in its header.

<Callout>
  Always open the mobile panel from the match's own control panel, or bookmark it once it's open.
  The link carries the match, which is what ties the phone to the right displays.
</Callout>

## What's on the screen

| Area | What it does |
| --- | --- |
| **Score buttons** | One column per team. The buttons match your sport — for example **+1**, **+2** and **+3** for basketball. |
| **−1** | Takes a point off that team, to correct a mis-tap. |
| **F** | Shows the team's fouls (or faults). Select it to add one. |
| **START / STOP** | Starts or stops the match clock. |
| **Time** | Opens the clock setter: presets from 5 to 45 minutes, or type minutes and seconds and select **Set**. Setting the time also stops the clock. |
| **◀ and ▶** | Move back or forward one period. The labels follow your sport — quarter, half, set or game. |
| **Home / — / Visitor** | Sets possession. |
| **Undo** | Reverses your last action. |
| **Reset Match** | Starts the match again from the beginning, after a confirmation. See [Using the control panel](/running-a-match). |

## Who's in control

A bar under the header shows whether your phone is scoring the match:

- **IN CONTROL** — your taps change the score.
- **VIEWING ONLY** — another panel has control. Select **Take Control** to take over.

Only one panel scores a match at a time, and a phone counts as a panel like any other. If you have
the full panel open on a laptop as well, whichever one took control last is the one that scores.
See [Sharing control of a match](/running-a-match/sharing-control).

## What the mobile panel can't do

Use the full control panel for these:

- **Ending a period.** The ◀ and ▶ buttons only change the period number. They don't stop the
  clock, reset it for the next period, or clear the score for set-based sports the way
  **End Period** does on the full panel.
- **Cricket and softball.** These sports have their own scoring panels, which aren't available on
  the mobile panel.
- **Indoor cricket wickets** and **timeouts.**
- **Clearing fouls.** You can add a foul but not reset the count.
- Team names, the match name, colours, logos, the theme, sounds, display links and ending the
  match.

## Tips

- Keep the phone's screen from locking during play. If it does lock, the panel reconnects when you
  unlock it — check the bar still says **IN CONTROL** before you carry on.
- On a weak connection, watch the connection badge in the header. If it shows **OFFLINE**, taps
  aren't reaching ScoreHub; see [Troubleshooting](/support/troubleshooting).

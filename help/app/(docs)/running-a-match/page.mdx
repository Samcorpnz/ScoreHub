# Using the control panel

The control panel is where you run a match. Open it from the
[dashboard](/running-a-match/dashboard-and-fixtures) with **Open Control** (a live match) or
**Start** (an upcoming one), or arrive there automatically after
[setting up a new match](/getting-started).

It has six tabs:

| Tab | What it's for |
| --- | --- |
| **Score** | Running the match — clock, score, period, fouls, possession. |
| **Outputs** | Links for every display, plus Graphics Control and the Player Roster. See [Venue screens, OBS and vMix](/displaying-your-score/obs-and-venue-screens). |
| **Logos** | Team logos. See [Branding your displays](/displaying-your-score/branding). |
| **Theme** | Colours, font, text size and competition logo for your displays. |
| **Audio** | [Sound cues](/running-a-match/sound-cues) that play at set clock times. |
| **Settings** | Team names and colours, the match name, match defaults, ending the match, and tokens for Bridge and Stream Deck. |

This page covers the Score tab for most sports. [Cricket](/sports/cricket) and
[softball](/sports/softball) replace it with their own panels.

## The clock

- **START / STOP** is the large button at the top. It starts and stops the match clock.
- **Adjust clock** nudges the clock by 1, 10 or 60 seconds in either direction.
- To set an exact time, type it in the **MM:SS** box and select **Set**.
- **Count down / Count up** switches the clock's direction. Each sport starts with the right
  direction for its template, so you'll rarely need this.

## Scoring

Each team has a card with a button for every score value in its sport — for example **+1**, **+2**
and **+3** for basketball — and a matching minus button to take points back off. Scores can't go
below zero.

Under the score buttons:

- **Fouls** (basketball) or **Faults** (other sports) adds one to the team's count each time you
  select it. **Reset** puts it back to zero.
- **Home ball / Visitor ball** sets which team has possession. Select the active one again to
  clear it.

## Ending a period

**END** followed by the period name (**END QTR**, **END HALF**, **END SET** and so on) does several
things at once: stops the clock, moves to the next period, resets the clock to the period length,
and marks a break so displays show it — **HALF TIME** at the middle of the match, **FULL TIME** after
the last period, and otherwise the period name and **BREAK**. For sports scored in sets or games — volleyball, tennis,
pickleball, badminton, table tennis and squash — it also resets both scores to 0–0.

**REOPEN** goes back one period and clears the break. Use it if you ended a period by mistake.
It doesn't restore scores that were reset — use **UNDO** straight away for that instead.

## Extra time

Sports played in quarters, halves or periods can go to extra time. Ending the last regulation
period shows **FULL TIME** on displays and sets the clock for extra time. From there:

- If the match is decided, end it from the Settings tab.
- If it's going to extra time, start the clock. The periods that follow show as **ET 1**, **ET 2**
  and so on, and **END ET** moves from one to the next.

Each extra-time period starts on the sport's usual length:

| Sport | Each period starts on | Shown as | Usual format |
| --- | --- | --- | --- |
| Netball | 7:00 | ET | Two halves, then play on until a two-goal lead |
| Fast5 netball | 1:00 | ET | One period, then next goal wins |
| Basketball | 5:00 | OT | Repeated until there's a winner |
| Handball | 5:00 | ET | Two halves, played twice if needed |
| Futsal | 5:00 | ET | Two halves |
| Floorball | 10:00 | ET | One period, first goal wins |
| Hockey | 7:30 | ET | Two halves — many competitions now go straight to a shoot-out |
| Water polo | 3:00 | ET | Two halves — many competitions now go straight to a shoot-out |
| Touch rugby | 2:00 | DROP-OFF | A player leaves each side every period |
| Football, rugby union | Counts up from 0:00 | ET | Two halves |
| Rugby league | Counts up from 0:00 | GP | Golden point — first score wins |

Competitions often play something different, so you can set the length for each match: under
**Clock & Match Controls**, type it into **Extra time — length of each period** as `MM:SS` and
select **Set**. You can do this at any time before extra time starts. If you change it while an
extra-time period is waiting to start, the clock moves to the new length too. Sports whose clock
counts up don't have a length to set.

## Penalty shoot-outs

Football, futsal, handball, hockey, water polo and floorball have a **Start penalties** button
(**Start shoot-out** for hockey) on the Score tab, under the score cards. Selecting it stops the
clock and opens a shoot-out card with both teams side by side.

- **✓ Scored** and **✕ Missed** record that team's next attempt.
- **Remove last** takes back that team's most recent attempt. **UNDO** works too.
- **Clear shoot-out** removes the tally from the control panel and every display.

The shoot-out is tallied apart from the match score, which stays as it stood at the end of play.
Displays show the tally where the period normally is — for example **PENALTIES 4 – 3**, with a
filled dot for each attempt scored and a hollow one for each miss. The stream overlay and scorebug
show it on one line, such as **PENS 4–3**. ScoreHub doesn't decide the winner or stop you after a
set number of attempts, so sudden death just carries on. The tally stays on displays until you
clear it, reset the match or end the match.

The shoot-out is scored from the desktop control panel only — not yet from the phone control page,
Stream Deck or the Control API.

Sports scored in sets, games, ends or innings don't have extra time.

## Undo

**UNDO** reverses your last action — a score, a foul, a clock change, ending a period, even a
match reset. You can step back through your last 50 actions. Updates that came from a scoring
console through Bridge, and the clock ticking, aren't undoable.

## Keyboard shortcuts

Shortcuts work on the Score tab whenever you aren't typing in a text box. The panel shows the
same list at the bottom, with the values for the current sport.

| Key | Action |
| --- | --- |
| `Space` | Start / stop the clock |
| `Ctrl+Z` or `⌘Z` | Undo |
| `1` `2` `3` `4` | Home: add the first, second, third or fourth score value |
| `Q` `W` `E` `R` | Home: subtract the first, second, third or fourth score value |
| `9` `0` `8` `7` | Visitor: add the first, second, third or fourth score value |
| `O` `P` `I` `U` | Visitor: subtract the first, second, third or fourth score value |
| `[` `]` | Previous / next period |

A sport with a single score value, such as football, only uses `1`, `Q`, `9` and `O`. Score values
are numbered left to right, smallest first, so in rugby union `1` is a conversion and `3` a try.

<Callout>
  `[` and `]` only change the period number. They don't stop the clock, reset it, or reset set
  scores the way the **END** button does.
</Callout>

## Changing names during a match

Team names and the match name are on the **Settings** tab: each team's card has its name above its
colour, and **Match Name** has its own card. Each box shows the current name — change it and select
**Set** (or press Enter). Displays update immediately. A blank name isn't saved, so you can't
accidentally wipe one.

To change the period number, use **Period / Quarter** under **Clock & Match Controls** on the Score
tab.

## Timeouts

For sports with timeouts, each team's card on the Score tab has two buttons under the fouls row:

- **Timeouts left** — select it when that team takes a timeout. The count drops by one and
  displays update.
- **Restore timeout** — adds one back, up to the sport's allowance. Use it to fix a mis-tap, or to
  top teams back up at a new half or period if your competition's rules reset timeouts.

A new match starts with the sport's full allowance. Timeouts don't reset on their own between
periods.

## Reset Match

**Reset Match** starts the same match again from the beginning. It sets scores and fouls back to
zero, returns to the first period and restores the sport's starting clock. For cricket, softball
and indoor cricket it also clears the innings, outs and wickets scored so far.

Everything you set up is kept: the sport, match name, match options, team names, colours, logos,
squads and your display theme. Timeouts are left as they are.

It asks you to confirm first, and it can be undone with **UNDO**.

## Changing sport

A match's sport is set when you set it up and can't be changed once the match exists — the
**Settings** tab shows it, but doesn't let you switch it. To score a different sport, go back to
the dashboard and set up a new match.

## Resetting to the sport's defaults

On the **Settings** tab, **Apply Template Defaults** puts the match structure back to its sport's
defaults: it stops the clock, sets
the clock time and direction, returns to period 1, sets possession, clears both teams' fouls and
restores their full timeout allowance. Scores, names and colours aren't touched.

## Ending the match

When the match is over, open the **Settings** tab and select **End Match**. The clock stops, the
match moves to **History** on the dashboard, and its score is locked — the control panel, Stream
Deck, the Control API and Bridge can no longer change it. Displays keep showing the final score. On the
Free plan, this is also what frees you up to start your next match.

Admins, Managers and Operators can end a match.

## Correcting a match after it has ended

An ended match has to be reopened before anything can be changed.

1. On the dashboard, open the **History** tab and select **Reopen** on the match.
2. Confirm. The match becomes live again and its control panel opens.
3. Make the correction, then select **End Match** on the **Settings** tab again.

If a control panel is still open on a match that has ended, it shows **This match has ended** with
a **Reopen Match** button that does the same thing.

A reopened match is a live match. On the Free plan you can't reopen one while another match is
live — end that one first. See [The Free plan's one-match limit](/billing/free-plan-limit).
Admins, Managers and Operators can reopen a match.
